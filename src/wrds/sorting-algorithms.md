## Sorting algorithms statistics

| Algorithm      | Worst-case running time  | Average-case/expected running time |
| -------------- | ------------------------ | ---------------------------------- |
| Insertion sort | &Theta;(_n_<sup>2</sup>) | &Theta;(_n_<sup>2</sup>)           |
| Merge sort     | &Theta;(_n_ lg*n*)       | &Theta;(_n_ lg*n*)                 |
| Heapsort       | O(_n_ lg*n*)             | -                                  |
| Quicksort      | &Theta;(n<sup>2</sup>)   | &Theta;(_n_ lg*n*) (expected)      |
| Counting sort  | &Theta;(_k_ + _n_)       | &Theta;(_k_ + _n_)                 |
| Radix sort     | &Theta;(_d_ (_n_ + _k_)) | &Theta;(_d_ (_n_ + _k_))           |
| Bucket sort    | &Theta;(_n_<sup>2</sup>) | &Theta;(_n_) (average-case)        |

O - assymptotic upper bound.  
&Theta; - assymptotically tight bounds.
